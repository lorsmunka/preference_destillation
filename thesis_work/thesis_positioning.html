Thesis positioning: an adversarial review

Is the project worth doing, what is new in it, what an examiner will attack, and what cheap additions close the gaps. Reviewed 2026-10-08 against the repo state at commit 44c6ff3 (PLAN v2, tutor corpus done, cloud teacher run not yet started). Local file. Every outside source in the list at the bottom was opened during this review; items I could not check are marked.

TL;DR Red team (15) Why worth doing Novelty and low-hanging fruit Recommended framing Cheapest additions Corrections to earlier notes Sources

TL;DR

  • Worth doing: yes. It holds up as a framework thesis, which is what the assignment asks for. It has one sharp empirical rule: soft labels matter in proportion to teacher entropy. It also has an extreme-scale agent case study: a from-scratch tutor of a few million parameters inside a harness, three to four orders of magnitude smaller than its 12B teacher.
  • What survives as novel: the combination of from-scratch, tiny, domain-only and agentic, with token-level teacher distributions (a). Also the test of the entropy rule inside one agent, across turn types (d), and training a from-scratch output head on a task-derived token subset with the teacher renormalised to it (the narrow half of b).
  • What does not survive: a task-derived vocabulary as such (VocabTailor [30]). What-if follow-ups with solver-computed answers (MathCAMPS [39]). Soft labels on a gold target (Kim & Rush word-level KD [2]). Out-of-scope handling in the runtime (NeMo Guardrails [27]). Annealed KL/CE (LLM4Teach [20]). Offline stored logits (DistillKit [58]). Cite these, don't claim them.
  • Biggest exposures: no pretrained-baseline row, no classifier-router baseline, test messages only from LLMs, and no check that explanations are faithful. Two assignment items are not yet visible in the repo: a test suite and a phone (or CPU) run.
  • Cheapest fixes, about 1.5 working days for the top three: (1) before the cloud run, log the in-vocabulary probability mass and compare NF4 with bf16 on a sample; (2) per-turn-type exp(H) plus gold-history vs own-history evaluation, neither needing new training; (3) a bag-of-words router and a SmolLM2-135M row.

2 Distillation adds nothing over SFT on teacher text, and your own E-01 says so. high Own it, because it is the finding. E-01 is null on reddit and math (exp(H) 1.021 / 1.003; 10 seeds; noise floor ±1.8 / ±1.7 pp). Close: before any tutor training, compute exp(H) per turn type (route / solve / explain) from the stored logits and write the prediction down: the arms separate on explain, not on route or solve. Template messages: NN 0.385, 4.3% near-duplicates. On the free-written set the teacher routes 175/180. The weak spot: the "free-written" messages are also LLM-written, and human-machine conversations differ sharply from the data systems are built on [51]. Close: score the student on templated vs free-written messages; the gap is the template-overfit number. Have the planned ~100-message routing test written by people who never saw the templates. 2-3 h. Templates also cut the other way: GSM-Symbolic shows accuracy swings when only the numbers change [38], so report the spread across the renumbered copies of each test item. That is free, because the copies exist.

Google's QAT result (54% smaller perplexity drop at Q4_0 [18]) concerns its own QAT checkpoints, not bitsandbytes NF4, so it is no defence of NF4. 5 SVAMP is easy and contaminated. medium Contamination is a pretrained-model problem: GSM1k shows drops of up to 8% [37]. A from-scratch student sees only its corpus, which was leak-checked against all 1,000 SVAMP problems (0 leaks). SVAMP was built as a challenge set against shallow heuristics [36]. The 746-problem filter (1-3 operations, numbers ≤ 99, grade ≤ 4) matches the grade 2-4 scope. The real weakness is lexical: 72.5% of SVAMP problems contain an input token the student never saw (4.1% of all tokens). Close: report SVAMP per shape (577 one-step / 169 two-step) with the planned UNK + input-dropout fix, plus an ablation where the harness maps unseen names to known ones. Also check the output side: render SVAMP's gold facts-first lines and count the tokens missing from the 18,357-token output head. A missing name means the student cannot write that fact line. Zero GPU, ~1 h.
6 A classifier could route, so "agentic" is a stretch. med-high Partly true. Intent detection with under 0.59M parameters reaches 98% on SNIPS [53], and out-of-scope detection is a standard task [52]. But the agent does more than route: it solves in facts-first lines the harness checks, explains, holds firm under pushback, and works inside a harness that keeps a main line and a side thread. Define "agentic" as in novelty_check: a response type per message plus structured output that the harness checks and acts on. Anchor "agent = model + harness" in the agent-distillation roadmap, which treats harnesses as a place where knowledge is kept [24]. Close: train a bag-of-words logistic-regression router on the same route records and report it next to the student's first-token route accuracy. 1-2 h CPU. If the classifier wins, the harness can use it, and that is the modularity claim at work.
7 The student is too small to explain anything faithfully. high Fluency below 10M parameters in a narrow domain is shown [9]; faithfulness is the open question. Explanations are the high-entropy turn, and they use the large output head. Today's harness check catches only take-backs and agreeing with a wrong answer (1/165 take-backs caught in the teacher pilot). It does not check that the numbers in an explanation are right. Close: (a) a number-grounding check: every number in an explanation appears in the context or is a true calculation. It is automatic from the trace; 2-3 h. (b) Run the size study (Study 3) on explain turns first, varying depth as well as width, since depth matters at small scale [15]. (c) If explanations fail at the chosen size, narrow the claim to route + solve and report the size at which explain works. That is a result, not a failure.
8 No human evaluation. med-high Every current metric is automatic and checkable: answer = code, line validity, route, held firm. LLM judges agree with humans over 80% of the time but carry position, verbosity and self-enhancement biases [55]. Learning outcomes need a field study [45] and are out of scope. Close: a small blind rubric study. 40 conversations, student vs teacher, 2-3 raters scoring correct / child-readable / holds firm, with Cohen's kappa. About 1 day. Never claim a learning effect.
9 One agent on one domain: nothing generalises. medium Part 1 already spans four domains on one pipeline, with seven points on the entropy axis (E-00: math 1.003, reddit 1.021 with fields at 1.02-1.09, post-gen 2.73). Part 2 is a case study by design. The tutor's turn types give an entropy axis inside one domain, which removes the domain confound that part 1 cannot. Close: state the scope plainly. 10 The framework duplicates existing distillation toolkits. medium TRL's GKDTrainer wraps SFTTrainer around pretrained HF models with on-policy generalised JSD [57]. DistillKit already offers offline distillation from compressed stored logits with KL/JSD/TVD losses, and its configs use pretrained students such as Qwen3-8B [58]. EasyDistill covers black- and white-box KD with SFT, ranking and RL [59]. None of their documentation shows: from-scratch tiny students with a task-derived output head; domain plug-ins (prompt + vocabulary slice + metric + corpus); distribution metrics logged during eval; or an agent harness whose training records come from the same Conversation class it runs with. Close: one feature table marking each item documented or not documented. Make no novelty claim for offline logits or the divergence zoo.
11 A reduced vocabulary is not new, and restricting KL to it biases the teacher. medium The idea is not new. TinyStories keeps the top 10K tokens [9]. Vocabulary trimming removes other languages' tokens [29], and Compact prunes by global frequency [31]. VocabTailor builds a task-specific static LM-head subset from task corpora, training-free, on pretrained SLMs [30]. On bias: caching top-K teacher probabilities gives biased estimates of the teacher [33]. The fixed subset renormalises the teacher in the same way, and the mass outside it is not logged today. Close: log the in-vocabulary mass (logsumexp over the subset minus logsumexp over the full vocabulary) in ReducedLogitsRecorder and score_training_examples. The full logits are already in memory at both points. About 10 lines, before the cloud run; report the mean and the 1st percentile per turn type.
12 Three seeds over ~70 runs and many comparisons: the effects are noise. medium The noise floor is measured: ±1.8 pp reddit and ±1.7 pp math at n=10, and post-gen seed std .001-.002. Few student projects have that. Data order, initialisation and hyperparameters are known to swing benchmark results [56]. Close: name one primary comparison per study in advance, use paired seeds, report differences in seed-std units, and label the rest exploratory. Give the headline row 5+ seeds rather than 3 seeds everywhere.
13 Trained on gold histories, deployed on its own: errors compound across turns. medium This is known at token level, as exposure bias, and on-policy distillation targets it [5][6]. It is also known at conversation level. In MT-Eval's gold- vs self-generated-history ablation, Vicuna-13B's recollection score rises from 4.64 to 7.32 with gold history [50], and LLMs lose 39% on average when a task is spread over turns [49]. The harness limits this: a solution is checked, asked for once more if it fails, and tidied before it enters the history, and a new task drops the side thread. Close: run each test conversation twice, once with gold history and once with the student's own, and report accuracy per turn index. Same harness, no training, 3-4 h. This is fruit (e) below.
14 A tutor that hands out answers harms learning, and children's safety is ignored. medium The evidence is real. In Bastani et al., unrestricted GPT-4 raised practice grades by 48%, but grades fell 17% once access was removed; a safeguarded tutor largely removed the harm [45]. MathDial reports that LLM tutors give wrong feedback and reveal solutions too early [40]. Scope: the thesis distils behaviour. Teaching policy, such as hint first or withhold the answer, is a harness module. Wellbeing messages are already a stated limitation (domain_specs.txt). A tutor that evaluated learning outcomes or steered learning would enter the EU AI Act's high-risk list (Annex III 3(b)) [61]. Close: one limitations paragraph. Do not claim learning gains or child safety.

Why this is worth doing

1. Agents repeat narrow skills, so small models are the economical choice

An NVIDIA position paper argues that agents invoke "a small number of specialized tasks repetitively", and that serving a 7B SLM is 10-30× cheaper in latency, energy and FLOPs than a 70-175B LLM [25]. This project goes to the far end: the part-1 student (3.4M parameters) is about 1/3,500 of its 12B teacher.

2. Privacy and offline use for children

A model that runs on the device keeps a child's messages local. In the EU, offering an information society service directly to a child under 16 needs parental consent; member states may lower the age to 13 [60]. Running locally reduces data processing; it does not remove the obligations. Small on-device models are practical [17].

3. Verifiability and control

Answers come from executing code, every solution line is checked, and the closed output head limits what the model can say. LLM tutors give factually wrong feedback and reveal solutions too early [40]; grounding a tutor in verification makes its responses more often correct, with fewer hallucinations [44]. LLMs flip their answer 46% of the time when asked "Are you sure?" [48]. The teacher pilot held firm in 116/116 sweep pushbacks and 59/60 probes, and that behaviour is in the training data.

4. A scientific question with a measured answer

When do soft labels [1] beat imitation? E-01 says: in proportion to teacher entropy. Theory agrees [3], and part 2 tests it within one agent. A second question: how small can the model inside an agent be when the harness carries the state and the checks? Agent distillation with pretrained students goes down to 0.5-0.6B [22][23] (and to GPT-2 sizes in [21], per novelty_check.md). The only from-scratch agentic analogue is an RL policy of 24K / 10M parameters [20].

5. Reproducible on student hardware

The whole pipeline fits a 12 GB card plus one cloud rental. Stored teacher distributions let every loss ablation rerun without new teacher calls. That is the same practical case that makes DistillKit ship offline distillation [58]. The design is a reasonable one, not a novel one.

Recommended framing

Title-level claim

EN: A modular framework that distils a 12B teacher into from-scratch students of a few million parameters, showing on four domains and inside one agent that soft labels matter in proportion to teacher entropy.

HU (suggestion, keeps the assigned title): Keretrendszer nagy nyelvi modellek tudásának desztillációjára kis méretű, szakterület-specifikus modellekbe és ágensekbe. Possible subtitle: "a tanító entrópiája határozza meg, mikor számít a lágy címke" ("the teacher's entropy decides when soft labels matter").

Three contributions

  1. The framework (system contribution). Domain plug-ins (teacher prompt, vocabulary slice, metric, corpus); stored bf16 teacher distributions over a reduced vocabulary, verified bit-exact; typed TrainingRun dials (anneal, divergences, decoupled temperatures, entropy weighting, attention noise); distribution metrics logged during eval; and an agent harness whose training records are built by the same Conversation class it runs with. Evidence: 115 E-01 runs through one pipeline.
  2. The entropy rule (empirical contribution). Distillation's gain over imitation tracks teacher entropy. It is null at exp(H) ≈ 1 (reddit, math; 10 seeds, ±1.8 pp) and strictly ordered at exp(H) = 2.73 (post-gen, ~7 seed std). The prediction is then tested again inside one agent across route, solve and explain (pending Study 2).
  3. The agent case study (demonstration). A from-scratch tutor student of N M parameters inside a harness. It routes, solves with code-verified facts-first lines, explains, and holds firm against computed pushback. Measured on SVAMP (never trained on), held-out shapes, free-written and human-written messages, with gold- vs own-history evaluation and one pretrained-baseline reference row.

Three claims to avoid

  1. "A task-specific / reduced vocabulary is our idea." VocabTailor [30], TinyStories [9] and vocabulary trimming [29] have it. Say "a from-scratch head trained on the teacher's distribution restricted to a task-derived subset" and report the kept mass.
  2. "The tutor helps children learn" or "is safe for children". There is no learning study, no real pupils and no wellbeing handling [45].
  3. "From-scratch beats pretrained" or "KD beats SFT" in general. Random init costs about 10 points [10]; your own E-01 is null at low entropy; and whether distillation beats supervised training depends on the compute regime [14].

Also drop, or cite as prior art: annealed KL/CE mixing [20][13], what-if follow-ups with solver answers [39], offline logit storage [58], out-of-scope handling in the runtime [27], soft labels on gold [2].

Revised novelty sentence (amends novelty_check.md)

"To our knowledge, no prior work distils a large language model into a randomly initialised student of a few million parameters, trained only on one narrow domain, that then works as a conversational agent inside a harness: it chooses a response type per message and emits structured outputs the harness validates, learning from the teacher's token-level distributions restricted to a task-derived output vocabulary. Each ingredient has precedent: from-scratch logit distillation in general pretraining [12][13][14]; from-scratch small models on narrow LLM-generated text [9][10]; agent distillation into pretrained 0.1-7B students [21][22][23]; task-derived vocabulary subsets for pretrained models [30]; and solver-checked follow-up questions [39]. The closest from-scratch agentic analogue distils an LLM's action distribution into a reinforcement-learning policy [20]."

Corrections to earlier notes

  • novelty_check.md, "not found: a task-derived output vocabulary" no longer holds. VocabTailor derives a static LM-head subset from task corpora [30]. What survives is training a from-scratch head on that subset with KL to the renormalised teacher.
  • novelty_check.md, BabyLM "bans using a teacher's distribution" holds only for the 2025 Interaction track ("the external model's weights, hidden states, or output distribution cannot be revealed"). The other tracks permit any training objective within the data limits [19].
  • MathCAMPS [39] already generates counterfactual follow-ups whose answers come from the solver. The tutor's what-if mechanism is its close relative; cite it.
  • Provenance gap: batches/*/info.json records no teacher precision (NF4 vs bf16).
  • Doc drift: CLAUDE.md still describes the teacher as Gemma 3 4B with a ~525-token output vocabulary. Part 2 uses Gemma 4 12B with an 18,357-token tutor head.
