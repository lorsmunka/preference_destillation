Math tutor design (agreed):
- Item = word problem + answer + Python function that computes it, plus up to 3
  follow-ups, each with its own function taking the previous state. Answer = what the
  code returns; coherence across follow-ups is checked by execution, never trusted.
- Writing: ~10 style/sub-domain agents, each owning a slice (taxonomy cell: change /
  combine / compare / equal groups / partition, unknown position, grade band, distractor
  style, contexts). Two sources: agents search online for datasets/exemplars, agents
  write from memory conditioned on exemplars. Claude writes inputs; Gemma 4 12B stays teacher.
- Dedup: normalise (numbers -> N, names -> NAME), drop exact matches and > ~0.8 word-
  trigram Jaccard; second dedup on the function's operation chain for structure balance.
- Real datasets (SVAMP, ASDiv, MAWPS, GSM8K grade 2-4 integer subset): exemplars + the
  real-world held-out test. Never trained on. Also hold out whole operation-chain shapes.
- No scaffold in the prompt (v1 handed over A=? B=? C=A+B=?). Start with 1-2 digit numbers.
- Provenance stated in the thesis (TinyGSM precedent, 2312.09241).
