FEATURES LEDGER — what got added to the toolkit, one line each
Newest at the bottom. All dials live on TrainingRun (library/specs.py);
every one defaults to the old behaviour, so existing runs reproduce.

2026-09-15
- teacher_temperature_start / _end   teacher softmax gets its own schedule (the entropy dial); None = coupled to student temperature as before
- divergence                         forward_kl (default) | reverse_kl | js | tvd — the #38 zoo, offline on stored logits
- entropy_kl_weighting               0..1; per-token KL weight blends scheduled ratio with teacher entropy / log V (idea #58)
- kl_ratio_cycle_epochs + _amplitude oscillating annealing (idea #36); cycle length in epochs, amplitude as +/- around the schedule; 0 = off
- attention_noise_start / _end       gaussian sigma on attention logits, training only, cosine-annealed; start > end = fade out (idea #30)
- logs                               train_batch records now carry teacher_temperature and attention_noise
- (no new param) CE->KL vs KL->CE    already expressed by kl_ratio_start/_end: start < end is CE->KL, start > end is KL->CE
- batch storage                      batches/<domain>/<teacher>/batch_N.npz: bf16 logit bit-patterns + JSON strings; ~5x smaller, up to 48x faster to load, bit-exact; readers accept .npz or legacy .jsonl; python convert_batches.py migrates
- data-gen loop (KV cache)         ModelHandler feeds the prompt once and then one token per step through a DynamicCache (the path model.generate takes) instead of re-feeding the whole prefix; stops on EOS / end-of-turn; skips a leading "thought\n<channel|>" scaffold. Fixes stray-token corruption on Gemma 4 via bitsandbytes; 4/4 clean on reddit, maths, Virág. Not bit-identical to the old loop on Gemma 3 bf16 (near-tie flips ~1 in 5 examples); existing batches were made with the old loop and stay as they are.
- domains_report.py                 python domains_report.py -> thesis_work/domains.html: one tab per domain — spec, teacher prompt, datasets on disk with vocab size and entropy, and a dropdown of real stored examples (input / teacher response / ground truth where it exists). Local file.

2026-10-04
- generation_batch_size              GenerationJob dial: inputs generated together through one left-padded model.generate; reduced-vocab logits captured per step by a LogitsProcessor. 1 = the old loop. 4070/NF4, batch 16: 71/73 outputs identical to one-at-a-time (2 near-ties), 3.3x faster
- ground truth + answer_correct      corpus records with "answer" carry it into the batch files next to the teacher response, plus the domain's verdict (Domain.answer_matches). Nothing is dropped; the flag allows a correct-only training arm later
- fix: final partial batch           was numbered like the last full batch and overwrote it; Virág lost 32 of 5,000 examples (4,968 on disk). Now numbered ceil(saved / batch_size). Other datasets ended on full batches
- thought scaffold                   Gemma 4's "<|channel>thought\n<channel|>" spelling is skipped like "thought\n<channel|>" (4/75 math_tutor rejections before)
- math_tutor domain                  library/domain/math_tutor: human benchmarks, validator (own interpreter, solve() never exec'd), six-stage pruning, renumbering, writer brief; spec in domain_specs.txt; report: python math_tutor_report.py
