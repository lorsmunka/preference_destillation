PROJECT SUMMARY — PREFERENCE DISTILLATION
==========================================
Generated: 2026-03-18


WHAT IS THIS PROJECT?
---------------------
This is a university thesis proof-of-concept that distills domain-specific knowledge
from a large language model (Google Gemma 3 4B, 4.3 billion parameters) into tiny
custom-built transformer models (5M to 198M parameters). The student models use a
dramatically reduced output vocabulary (~525 tokens instead of 262,144 — a 99.8%
reduction) and learn to produce deterministic JSON output classifying Reddit comments
by tone, sentiment, safety, and toxicity. The project intentionally uses autoregressive
generation (not simpler classifiers) to prove the distillation technique works for
generative tasks. A second domain, math word problems, is also supported to demonstrate
the pipeline's generality.


THE CORE IDEA
-------------
A big AI model ("teacher") classifies Reddit comments and saves not just its answers
but its full probability distribution (logits) over every generation step. A much
smaller model ("student") then trains on these rich signals. The student learns both
HOW the teacher thinks (via KL divergence loss matching the probability distributions)
and WHAT the right answer is (via cross-entropy loss on the correct token). The ratio
between these two losses shifts over training: starting at 99% KL / 1% CE (learn the
teacher's thinking) and annealing to 30% KL / 70% CE (focus on getting the right
answer). This curriculum-style approach is grounded in distillation literature.


THE PIPELINE (3 stages)
------------------------
1. TEXT GENERATION: Collect raw inputs (Reddit comments from a database, or generate
   math word problems from 260+ templates with 13 operation types).

2. DISTILLATION DATA GENERATION: Feed inputs to Gemma 3 4B. At each autoregressive
   step, capture the teacher's logit distribution over the reduced vocabulary (~525
   tokens for sentiment, ~31 for math). Save as JSONL batches. Queue-driven, supports
   multiple domains. 500,000 examples generated for Reddit sentiment (complete).

3. TRAINING: Train a small decoder-only transformer on the teacher's outputs using
   the KL+CE curriculum loss. Queue-driven — define experiments in training_queue.json,
   leave running, come back and compare results across runs.


THE STUDENT MODEL
-----------------
Architecture: decoder-only transformer matching modern LLM design patterns.
Components borrowed from Gemma: RMSNorm (faster normalization), RoPE (rotary position
embeddings), GeGLU activation (gated feed-forward). Input vocabulary is full Gemma
(262,144 tokens — the student can read any text). Output vocabulary is task-specific
(~525 tokens for sentiment JSON, ~31 for math). The output projection layer is where
the dramatic size reduction happens.

--------------------------

  generation, training) with queue systems for both data gen and training.
- Generated 500,000 Reddit sentiment training examples with Gemma 3 4B logits.
- Ran pilot tests proving the concept works: a 537M parameter model achieved ~88%
  student-only accuracy and ~99% teacher-forced accuracy after just 3 epochs on

KEY INNOVATION
--------------
The novel combination is: task-specific output vocabulary reduction (99.8%) + full
input vocabulary retention + autoregressive structured output generation + dynamic
KL/CE loss annealing as curriculum learning. Output vocabulary reduction in distillation
is an underexplored area in the literature. The project demonstrates this works
for generative (not just classification) tasks across multiple domains.
