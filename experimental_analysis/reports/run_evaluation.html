Column glossary

What each column measures and how to interpret it.

Show all column definitions
Info
Status
Run status: completed or in_progress.
Architecture
Params (M)
Total trainable parameters in millions.
Hidden
Transformer hidden / embedding dimension.
Layers
Number of stacked transformer blocks.
Heads
Number of attention heads per layer.
Hyperparams
KL ratio
Loss blend: 1.0 = pure KL divergence (match teacher distribution), 0.0 = pure cross-entropy (match hard label). Shown as start->end if annealed.
Temp
Distillation temperature for softening teacher logits. Higher = softer distribution. Shown as start->end if annealed.
LR
Peak learning rate (cosine schedule with warmup).
Dropout
Dropout rate applied across all transformer dropout layers during training.
Training
Batches
Total number of training batches processed across all epochs.
Wall time
Wall-clock training duration.
Train loss
Average training loss over the last 200 batches.
Train acc
Average training token accuracy over the last 200 batches.
Evaluation
Eval loss
Total evaluation loss (KL + CE blend) on test set after the final epoch.
KL loss
KL divergence component of the final eval loss.
CE loss
Cross-entropy component of the final eval loss.
TF acc
Teacher-forced accuracy: ground truth tokens used as context. Optimistic upper bound.
Student acc
Student accuracy: model uses its own predictions as context (autoregressive). The realistic measure.
Class acc
End-task accuracy: parses generated JSON output and compares all category labels against ground truth.
F1 Scores
Tone F1
Macro-averaged F1 across the 5 tone classes.
Sent F1
Macro-averaged F1 across the 3 sentiment classes.
Safety F1
Macro-averaged F1 across the 2 safety classes.
Toxic F1
Macro-averaged F1 across the 2 toxicity classes.
Avg F1
Average of all four per-category macro F1 scores.
Curves
Stu slope
Linear regression slope of student accuracy across mini-eval checkpoints, in percentage-points per mini-eval (~1000 batches). Indicates learning steepness.
Cls slope
Same slope but on classification accuracy. Often more sensitive than student accuracy.
Early/late
Ratio of accuracy gained in the first half of training vs the second half. >1 = front-loaded learning, <1 = back-loaded.
Conv (0-1)
Fraction of training (0-1) needed to reach 90% of total accuracy gain. Lower = faster convergence.
Stdev
Standard deviation of student accuracy across mini-evals in the final epoch. Lower = more stable convergence.
Epoch deltas
E1 stu Δ
Change in full-eval student accuracy from epoch 0 to epoch 1.
E1 cls Δ
Change in full-eval classification accuracy from epoch 0 to epoch 1.
E2 stu Δ
Change in full-eval student accuracy from epoch 1 to epoch 2.
E2 cls Δ
Change in full-eval classification accuracy from epoch 1 to epoch 2.
Efficiency
Acc/M par
Student accuracy (%) per million parameters. Parameter efficiency.
Acc/hour
Student accuracy (%) per training hour. Compute efficiency.
