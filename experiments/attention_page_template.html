Explorer: one reply, token by token

Pick a test record, a set of models and a reply token: every panel shades the text by where that model looks while it writes the token (hover a token for its weight). Move with the buttons, the slider or the arrow keys (shift + arrow: 4 tokens). Gemma's panel is renormalised over the student's text; the share it puts on its instruction header and chat template, which the students never see, is shown above the text.

Study 1 · The baseline: how different are two seeds of the same student?

Question: before asking what KL, CE or size change, how much do two trainings with identical settings differ? Only a difference larger than that is a real effect of a setting.

Size m, 10 passes, full math data. A seed fixes both the start weights and the order of the data, and the same seed is used for every loss, so KL s1 and CE s1 start from the same weights and see the same batches: they differ only in what they learn from.
