### Data gen: s/example scales with model size, inversely with GPU bandwidth

Your 4B model at 2.2 s/example (midpoint) on 504 GB/s bandwidth.
12B = 3x larger model -> 3x more memory reads per token.
Faster GPU bandwidth directly reduces time proportionally.

| GPU      | Bandwidth | 4B s/example | 12B s/example | Derived from            |
|----------|-----------|--------------|---------------|-------------------------|
| RTX 4070 | 504 GB/s  | 2.2 (measured)| ~6.6         | 2.2 x 3 (model 3x)     |

| A100 80G | 2,039     | ~0.5         | ~1.6          | 504/2039 = 0.25x        |
| H100     | 3,350     | ~0.3         | ~1.0          | 504/3350 = 0.15x        |

Note: These assume bandwidth-bound autoregressive generation, which is correct
for single-example generation of models this size. Batched generation can
improve GPU utilization but needs more VRAM.

### Data generation: 12B model, 1,000,000 examples (2 domains)

12B VRAM requirements:
  BF16:  ~24 GB weights -> needs 32GB+ (RTX 5090 or A100/H100)
  INT8:  ~12 GB weights -> fits 24GB (RTX 4090)
  INT4:  ~6.6 GB weights -> fits anything

For distillation: BF16 logits are ideal. INT8 is very close. INT4 loses some
distribution detail. Recommendation: use BF16 if VRAM allows, else INT8.

--------------------------------------

  ~528 hrs (BF16) or ~361 hrs (INT8)
  Start this FIRST, it's the longest job.

Pod B (RTX 5090): Training — 40 experiments
  ~466 hrs
  Start simultaneously.

                  ~max(361, 466) = ~466 hrs = ~19 days (INT8)

CAN RTX 5090 RUN GEMMA 12B?
------------------------------
YES. 32GB VRAM is enough.

BF16 (24GB weights + ~6-8GB overhead):
  Fits on 32GB for your short sequences (max 75 tokens for sentiment,
  210 for math). KV cache is small at these lengths (~1-2GB).

INT8 (12GB weights + overhead):
  Fits easily with ~18GB headroom.

INT4 QAT (6.6GB weights):
  Fits trivially. Google has official QAT weights.

SETUP GUIDE: RUNPOD (step by step)
-------------------------------------

1. Go to runpod.io, create account
2. Add credits via credit card ($100 to start)
3. Click "GPU Cloud" in left sidebar
4. Find RTX 5090, click "Deploy"
5. Template: "RunPod Pytorch 2.x" (pre-installed CUDA + PyTorch)
6. Container disk: 50GB. Volume disk: 200GB (persistent storage for data/checkpoints)
7. Click "Deploy On-Demand" ($0.69/hr)
8. Wait ~30 seconds, click "Connect" -> "Jupyter Lab"
9. Open terminal in Jupyter
10. git clone <your-repo-url>
11. pip install -r requirements.txt (if needed)
12. cd preference_destillation/training && python main.py
13. STOP the pod when not running (billing stops, volume persists)


SETUP GUIDE: VAST.AI (step by step)
--------------------------------------

1. Go to vast.ai, create account, add $50 credits
2. "Search" tab -> filter: RTX 5090, sort by $/hr
3. Pick machine with >98% reliability, good internet speed
4. Docker image: "pytorch/pytorch:latest"
5. Click "Rent"
6. "Instances" tab -> click SSH button -> copy the command
7. Open PowerShell (Windows 11 has SSH built-in), paste command, type "yes"
8. Inside the machine:
     apt update && apt install -y git tmux
     git clone <your-repo-url>
     cd preference_destillation && pip install -r requirements.txt
     tmux new -s training
     cd training && python main.py
     # Ctrl+B then D to detach (keeps running if you close terminal)
     # tmux attach -t training   (to reconnect later)
9. "Destroy" instance on vast.ai when done to stop billing
